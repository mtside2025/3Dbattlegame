# Neon Clash

Three.js と Vite で作られた、ブラウザで遊べる3Dアクション対戦ゲームです。
プレイヤー「KAI」を操作し、円形アリーナを縦・横・斜めに自由に動き回りながら、CPUと戦います。

## ゲームの流れ

- 1試合は複数ラウンド制です。先に規定ラウンド数（通常ステージは2ラウンド、ボス戦は3ラウンド）を取った方が試合の勝者になります。
- 各ラウンドは60秒。時間切れの場合は残りHPの割合が多い方がラウンドを取ります。
- 試合に勝つたびに次のステージへ進み、敵のHP・攻撃力・反応速度・必殺技の使用頻度が上がります。
  1. STAGE 1: VIPER（紅蓮の拳士）
  2. STAGE 2: RAIJIN（雷迅の闘士）
  3. STAGE 3: KAGE（影の忍）
  4. FINAL: ZERO Ω（終焉の魔王） — 7本のビームを扇状に放つ固有必殺技「オメガ・ノヴァ」を使うボス
- 試合に負けた場合は、同じステージからコンティニューできます。

## 起動方法

リポジトリをZIPでダウンロードして展開し、ルートにある `index.html` をブラウザで開いてください。
`offline-assets` に Three.js を含む必要なファイルが同梱されているため、インストール、ローカルサーバー、インターネット接続は不要です。

ファイルを個別に移動せず、`index.html` と `offline-assets` の位置関係を維持してください。

### うまく動かないとき

- ZIPファイルをダブルクリックして中の `index.html` を直接開くと、`offline-assets` が読み込めず動きません。ZIPを右クリック →「すべて展開」してから、展開したフォルダ内の `index.html` を開いてください（読み込めない場合は画面に案内が表示されます）。
- 学校のPCなどで WebGL（3D描画機能）が無効になっている場合は、自動でソフトウェア描画に切り替わってゲームを遊べます。この場合は影などの演出が簡略化され、PCによっては動きが重くなることがあります。

## 開発方法

```bash
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開き、スタート画面の「ゲームスタート」または `Enter` を押してください。

## 操作方法

| キー | 操作 |
| --- | --- |
| `W` `A` `S` `D` / 矢印キー | 8方向に移動（奥・手前・左右・斜め） |
| `Space` | ジャンプ（ビームを飛び越えられます） |
| `J` | 弱攻撃「ジャブ」（素早く、リーチは短い） |
| `K` | 強攻撃「ハイキック」（遅いが、威力とリーチが高い） |
| `L`（長押し） | ガード（キャラクターの前にシールドが出現し、正面からの攻撃のダメージを軽減） |
| `L`（タイミングよく押す） | ビーム反射（ビームが当たる直前に押すと金色のシールドで跳ね返す） |
| `U` | ネオンビーム（ENERGY 30） |
| `I` | サイクロンキック（ENERGY 35・周囲をなぎ払う回転蹴り） |
| `O` | ライジングドラゴン（ENERGY 40・突進して打ち上げるアッパー） |
| `P` | メテオダイブ（ENERGY 55・跳び上がって地面に叩きつける衝撃波） |
| `Enter` | ゲーム開始・次へ進む |

攻撃は自動的に相手の方向を向いて繰り出されます。攻撃を当てる・受けることでENERGYがたまり、時間経過でも少しずつ回復します。
ガードは正面からの攻撃にのみ有効で、ダメージを完全には防ぎません。
反射したビームは速度と威力が上がって相手に向かいます。ビーム同士がぶつかると相殺されます。

## テストとビルド

```bash
npm test
npm run build
```

`npm run build` は、直接開けるファイルを `offline-assets` に再生成します。
