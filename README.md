# Neon Clash

Three.js と Vite で作られた、ブラウザで遊べる Street Fighter 風の3D対戦格闘ゲームです。
プレイヤー「KAI」を操作し、60秒以内にCPU「VIPER」のHPを0にすると勝利です。

## 起動方法

リポジトリをZIPでダウンロードして展開し、ルートにある `index.html` をブラウザで開いてください。
`offline-assets` に Three.js を含む必要なファイルが同梱されているため、インストール、ローカルサーバー、インターネット接続は不要です。

ファイルを個別に移動せず、`index.html` と `offline-assets` の位置関係を維持してください。

## 開発方法

```bash
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開き、スタート画面の「ゲームスタート」または `Enter` を押してください。

## 操作方法

| キー | 操作 |
| --- | --- |
| `A` / `D` | 左右に移動 |
| `W` | ジャンプ |
| `S`（長押し） | ガード |
| `J` | 弱攻撃（素早く、リーチは短い） |
| `K` | 強攻撃（遅いが、威力とリーチが高い） |
| `L` | 必殺技（ENERGYを40消費） |
| `Enter` | ゲーム開始・再戦 |

攻撃を当てるとENERGYがたまります。ガードは受けるダメージとノックバックを軽減しますが、ダメージを完全には防ぎません。

## テストとビルド

```bash
npm test
npm run build
```

`npm run build` は、直接開けるファイルを `offline-assets` に再生成します。
